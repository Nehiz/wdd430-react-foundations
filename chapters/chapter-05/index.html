Chapter 5 — Building UI with Components

This page demonstrates how React components are functions, must be capitalized, and are used as JSX tags (e.g. <Header />).

Notes & Quick Quiz

Try these quick experiments:

  1. Rename Header to header (lowercase) and observe the console error — React treats lowercase names as DOM tags.
  2. Try rendering the component without JSX syntax (e.g. root.render(Header)) — it errors because React needs an element (<Header />).
  3. Reuse <Header /> multiple times to see how components are reusable.
Quiz: How do you nest a Nav component inside a Layout component?

Answer: <Layout><Nav /></Layout> (component names must be capitalized and used like tags)
