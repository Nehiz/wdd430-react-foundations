# Chapter 7 — Adding Interactivity with State

Summary

- State is local, mutable data owned by a component. `useState` is the primary hook for local state in function components.
- Updating state triggers re-renders — design your state shape for minimal updates and easy reasoning.

Key takeaways

- Keep state minimal and colocate it where it is needed. Lift state up to the nearest common ancestor when multiple components share it.
