Chapter 4 — Getting Started with React

This demo shows adding React via UMD, using JSX with Babel standalone, and a couple of common JSX mistakes to learn from.

Try it

  1. Change CorrectName to correctName and attempt to render <correctName /> — see console errors.
  2. Try to render a function directly (e.g. root.render(Simple)) and observe the error; you must render an element (<Simple />).
